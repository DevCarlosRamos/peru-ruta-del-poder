# HISTORICAL SOURCES — CONTENIDO HISTÓRICO

## Criterio
Las cartas `[HISTÓRICO]` e `[INVESTIGACIÓN]` usan **hechos de dominio público** con
redacción neutral. Ningún evento de juego es una afirmación judicial sobre una persona.
